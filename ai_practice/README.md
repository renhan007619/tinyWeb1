# 重庆交通大学 - 交通运输学院论文关键词分析报告

## 项目说明

本项目针对**交通运输学院**各专业的论文数据进行分析，包括数据清洗、词频统计、词云可视化、以及专业与关键词的相似度计算。

## 文件结构

```
ai_practice/
├── data/
│   └── 论文信息.xlsx          # 原始数据文件
├── output/
│   ├── 词云图.png              # 生成的词云图
│   ├── 专业论文数量统计.png     # 各专业论文数量柱状图
│   └── 词频统计表.xlsx         # 词频统计结果
├── analysis_report.py         # 主分析脚本
└── requirements.txt           # 依赖包列表
```

## 运行步骤

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 运行分析脚本
```bash
python analysis_report.py
```

### 3. 查看结果
- 图表保存在 `output/` 目录
- 分析报告会在控制台输出

## 分析报告内容

### 1. 数据读取与清洗
- 读取Excel数据
- 筛选交通运输学院数据
- 处理缺失值和异常值
- 数据类型转换

### 2. 数据可视化
- 各专业论文数量分布
- 论文类型占比
- 年度趋势分析（如有时间数据）

### 3. 词频统计
- 对论文关键词进行分词
- 统计高频关键词
- 按专业分组统计

### 4. 词云图
- 生成交通运输学院整体关键词词云
- 分专业生成词云图

### 5. 相似度计算
- 计算专业与关键词的TF-IDF向量
- 计算余弦相似度
- 输出相似度矩阵

## 算法说明

### 相似度计算方法
使用**余弦相似度（Cosine Similarity）**：

```
sim(A, B) = (A · B) / (||A|| × ||B||)
```

其中：
- A、B 分别是专业和关键词的TF-IDF向量
- TF-IDF = 词频(TF) × 逆文档频率(IDF)

## 输出结果

运行后会生成：
1. 可视化图表（PNG格式）
2. 词频统计表（Excel格式）
3. 相似度矩阵（控制台输出）

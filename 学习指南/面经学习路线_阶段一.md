## 📅 每日学习安排

### Day 1：项目全景入门

### Day 2：Go基础-slice底层
**题目**：slice的底层是什么？扩容机制？  
**来源**：[百度日常 | 通用]

- **结合点**：看看tinyweb的handler里哪些用了slice，思考会不会有共享底层数组的风险
- **动手实验**：
  ```go

  fmt.Printf("len=%d cap=%d ptr=%p\n", len(s), cap(s), s)
  s = append(s, 1, 2, 3)
  fmt.Printf("len=%d cap=%d ptr=%p\n", len(s), cap(s), s)
  ```
- **难度**：⭐⭐⭐

### Day 8：Go陷阱-range
**题目**：for range遍历slice/map时变量内存地址是否变化？为什么会遍历赋值后值不对？  
**来源**：[字节一面]

- **类型**：Go进阶陷阱
- **经典bug**：
  ```go
  items := []Item{{"a"}, {"b"}, {"c"}}
  var ptrs []*Item
  for _, item := range items {
      ptrs = append(ptrs, &item)  // 错的！
  }
  ```
